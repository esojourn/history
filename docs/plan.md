# 历史可视化网站 · 项目计划

> 状态：v1.0（2026-11-21）展现形式已定稿为“时间长河”，正式开发中　｜　定稿前的可交互示例见 [prototypes/index.html](../prototypes/index.html)　｜　内容怎么写、怎么查证见 [content-guide.md](content-guide.md)　｜　待确认事项见 [第 9 节](#9-待确认的决定)

## 1. 目标与原始需求

做一个**直观展示各国历史**的网站。原始需求：

1. 支持多语言：先做中文，预留语言包翻译能力。
2. 先做中国历史：以朝代为主线，人物为节点，写清每个人物的年代、先后顺序与主要事件；人物之间的关联要直观地连线显示。
3. 覆盖其他主要文明；近代部分包含欧美、日本、韩国、东南亚各国等。
4. 古代史从圣经历史开始。

核心难点只有一个：**信息量极大，而屏幕很小**。下面所有设计都围绕"任何时刻只显示当前尺度下最重要的那一小部分"展开。

## 2. 展现形式：一条可缩放的"时间长河"

### 2.0 候选方案与结论

**结论（2026-11-20 项目方确定）：按方案 A“时间长河”定稿，方案 B、C 放弃。** B、C 的示例文件已从仓库删除（Git 历史里可找回），`prototypes/` 里只留方案 A 的示例。下表保留当时的比较，作为记录：

| 方案 | 一句话 | 最强 | 最弱 |
|---|---|---|---|
| **A 时间长河** | 横向时间轴 + 文明泳道，缩放时换一层内容 | 年代先后、多文明对照 | 上手要学缩放，制作量最大 |
| **B 历史长卷** | 像书一样纵向滚动，每个朝代一章 | 易读，手机体验最好，制作最简单 | 关系只是人名列表，不够直观 |
| **C 人物关系网** | 人物是点、关系是线的一张网 | 人物关系最直观 | 年代只有大致位置，放不下多文明 |

本节以下内容都是方案 A 的设计。人物之间的关系在时间长河上用连线表示，并在详情卡里按类型分组列出；每个人物、事件另有独立网址的页面，可以从头读到尾。

### 2.1 总体思路

主视图是一张**横向时间轴 + 纵向文明泳道**的大图，像地图一样可以拖动和缩放。缩放时不是简单放大，而是**换一层内容**（语义缩放）：

| 层级 | 屏幕跨度 | 显示什么 | 例子 |
|---|---|---|---|
| L0 世界 | 约 6000 年 | 各文明泳道、大时代色带 | 中国 / 圣经与以色列 / 近东 / 欧洲 … |
| L1 文明 | 约 1000–2000 年 | 朝代、政权色带，标志性事件 | 秦、汉、三国、晋 … |
| L2 朝代 | 约 100–300 年 | 人物**生卒条**、帝王在位条、事件点 | 刘邦、项羽、韩信；楚汉战争 |
| L3 人物 | 约 10–80 年 | 单个人物的生平事件、全部关系 | 韩信：登坛拜将 → 垓下 → 被杀 |

参考先例：Sebastian Adams 1871 年的《世界历史对照年表》（Synchronological Chart，正是从圣经纪年起笔）、Sparks 的 Histomap、微软 ChronoZoom。它们证明"泳道 + 时间轴"是承载通史最稳妥的骨架；我们在此基础上加上缩放、人物关系和多语言。

### 2.2 线框示意（L2：朝代层）

```
 时间 →     -230        -210        -190        -170        -150
          ┌───────┬──────────────────────────────────────────────
 朝代     │  秦   │                    西汉
          └───────┴──────────────────────────────────────────────
 帝王      秦始皇 ══╗二世   高祖 ═════╗惠帝═╗吕后══╗文帝 ═══════
 人物      项羽   ├────────────●┤
           刘邦  ├──────────────────────────┤
           韩信      ├─────────────────●┤          ● = 卒年/关键事件
           张良    ├──────────────────────────────┤
 事件               ▲陈胜吴广  ▲鸿门宴 ▲垓下之战   ▲白登之围
                    ╰──── 选中"韩信"后，连线亮起：刘邦(君臣) 项羽(敌对) 萧何(举荐) ────╯
```

- **人物 = 一根生卒条**，长度就是寿命，位置就是年代，先后顺序一目了然。
- **事件 = 时间轴上的点或短条**，与参与人物相连。
- **关系连线默认不显示**，选中或悬停某个人物时，才亮起他的关系线，其余内容变淡。这是避免"一团乱麻"的关键。

### 2.3 三个联动视图

| 视图 | 回答的问题 | 形式 |
|---|---|---|
| **时间长河**（主视图） | 谁在什么时候？谁先谁后？同一时期别处在发生什么？ | 泳道时间轴，语义缩放 |
| **关系图** | 这个人和谁有关系？是什么关系？ | 以所选人物为中心的 1–2 层关系网，连线按类型着色（亲属 / 君臣 / 师生 / 敌对 / 同盟 / 交游） |
| **详情页** | 这个人 / 朝代 / 事件的完整信息是什么？ | 独立网址的页面：简介、生平小时间轴、关系列表、相关事件、出处 |

三者共用同一份数据与同一个"当前选中对象"：在时间长河里点人物 → 侧栏出卡片 → 可展开关系图或进入详情页；在关系图里点另一个人 → 时间长河自动滑到他的年代。

### 2.4 控制信息量的五个手段

1. **语义缩放**：见 2.1，每层只显示该层的内容。
2. **重要度分级**：每个人物、事件带 1–5 级重要度，决定它在哪个缩放层开始出现（5 级在 L1 就可见，1 级只在 L3 可见）。
   - **有空就补**（2026-11-22）：重要度门槛只决定“一定要出现”的人和事。门槛以下的，只要那一段有空地方、名字不会和别人挤在一起，也照样显示，按重要度依次补进去；只往泳道已有的行里填（不足三行按三行算），泳道不会因此变高。原因：人物稀疏的时段（如圣经历史的马加比时期）原来只剩一两个人，画面很空，容易让人以为没有别的内容；人物密的时段（如秦汉之际）没有空地方，显示的和原来一样。重要的人行号固定，缩放时位置不跳；补进来的人缩放时可能换行。
3. **选中聚焦**：关系线、次要标签只对当前选中对象显示。
4. **筛选**：按类别开关——政治、军事、思想文化、科技、宗教、经济。
5. **搜索直达**：输入"苏轼"直接飞到 1037–1101 年并选中。

### 2.5 多文明并列

- 每个文明一条泳道，可折叠、可调序。中国泳道内部遇到并立政权（三国、南北朝、五代十国、宋辽金夏）时，自动拆成子泳道。
- **同期对照线**：鼠标所在年份拉一条竖线贯穿所有泳道，直接读出"公元前 221 年秦统一六国时，罗马正处在第二次布匿战争（前 218 年爆发）的前夕"。
- **跨文明连线**：张骞通西域、鉴真东渡、蒙古西征、鸦片战争这类事件，作为跨泳道的连线呈现——这是多文明放在一张图上最有价值的地方。

- **展开与收起**（已在示例中验证，2026-11-20）：到了人物层，11 条泳道不可能同时摊开在一屏里。每条泳道有两种状态：
  - *收起*：只剩这个文明的色带一条，人物和大事都不显示。
  - *展开*：按缩放程度显示全部人物，大事另起最多三行。
  - **泳道高度随眼前这一屏变化**（2026-11-22）：展开的泳道占多高，只看当前屏幕里（左右各多看一点）的人物和大事要几行；人少的时段泳道变矮，下面的文明跟着上移，左右移动或放大后人多了再变高。高度变化逐帧过渡，不会一下子跳。每个人的行号仍按整条泳道统一排，所以拖动时同一个人不换行。页面已经往下滚过时，屏幕最上方那条泳道保持在原位，眼前的内容不会因为上面的泳道变高变矮而跳走。原因：原来泳道高度按整条时间轴里最挤的时段来定，人少的时段下面留出一大片空白（如圣经历史的前 200 年前后）。
  - 默认只展开中国。在人物层，点文明的名称或它的色带就是展开或收起；另有“全部展开 / 全部收起”。（还没放大到人物层时，点色带是放大到那个时期。）
  - 选中某人时，他所在的文明自动展开；与他相关的人即使在收起的泳道里也会浮出来，关系线可以跨泳道。
  - 页面比屏幕高时，年份刻度钉在顶上，拖动同时管左右和上下。
  - 秦汉这 120 多年、69 个人物的实测：默认状态约一屏半高，全部展开约三屏高。

### 2.6 手机端

横向长图在手机上难用。手机端改为**纵向时间轴**（时间从上到下），所有文明并排连成一整张图，像地图一样连续缩放，不分层：

- **缩到最小**是几千年的全貌：每个文明一列（再窄也留一条），朝代、时代画成深浅相间的色块并竖写名称，人物缩成小色块。这时点图上任何地方都是“放大到这一段”。
- **放大以后**色块渐淡，人物竖条、人名、大事（每个文明最左边一列，◆）浮出来，可以点。
- **大事一列分左右两道**（2026-11-24）：右边一道是 ◆ 加竖写的名字，重要的先占位置，放得下才写；左边窄窄的一道放写不下名字的事——单独一件是小 ◆，挨得近的几件合成一个带数字的圆点，点开在底部抽屉里列出这几件事（年份、名称、两行简介），点哪一件看哪一件，卡片上的“返回”回到清单。持续多年的事，线画在名字左边，不压字。原因：原先写不下名字的事也画在同一道上，事情多的时段（如五代十国，五十年里十八件）小 ◆ 和竖线压在别的事件名字上，叠成一团，既看不清也点不准。为了放下两道，大事一列比人物的一列宽四成。谁写名字、谁和谁合并，按整个文明统一排，上下拖动时不会变来变去。
- 手指拖动、两指缩放、松手惯性都由页面自己处理（`touch-action: none`），不靠浏览器滚动；原先“浏览器滚动、页面只接两指”的做法在火狐上两指缩放没有反应。电脑上按住鼠标拖动、Ctrl + 滚轮缩放。为了跟得上手指，图一次多画出屏幕外一圈；手指移动、缩放时只把画好的图层整体平移、拉伸（CSS transform），停下来或快露出没画到的地方时才重画（2026-11-24，原先每动一下都整张重画，手机上极卡）。重画一次在手机上要几十毫秒，所以尽量少画（2026-11-24 再改，实测一次滑动的重画从十几次降到一两次）：手还在动时，多画的那一圈偏向前进的方向；松手后等约 0.1 秒才按停下的位置重画，这期间手指再按下来就不画，连着划不会越划越卡。小栏里有“全貌”（一键缩到最小）和 + −。顶上的文明标签跟着屏幕位置走，点一下滑到那个文明，停在同一年。
- **文明宽度随眼前变化**（2026-11-24，与桌面版泳道高度随屏幕变化同一个道理）：每个文明占多宽，只看屏幕上看得见的这一段里的人要用到几列（屏幕外预先画好的那一圈不算，那里放不下的人先不画，拖过去时再加宽；2026-11-24 改，原先连上下各一屏一起算，拖进人少的时段要再往下拖一屏文明才收窄）；人少的时段文明变窄，右边的文明跟着左移，拖到人多的时段再变宽。宽度变化一步到位，屏幕中间那个文明的左边缘停在原处，眼前的内容不跟着跳，只是右边的文明会一下子挪过去（2026-11-24 改：原先逐帧过渡，每一帧都要整张重画，每次松手连着重画十几次，手机上明显卡顿）。手还在动的时候，宽度按画出来的整段（含屏幕外那一圈）来定、只加宽不收窄，免得拖一小段就为加宽重画一次；停下来再收到眼前该有的宽度。每个人的列号仍按整个文明统一排，上下拖动时同一个人不换列。原因：原来文明宽度按整条时间轴里最挤的时段来定，如中国泳道在夏商时只有两三列有人，却占着南北朝那么宽，右边的文明要拖很远才看得到。
- **关系聚焦**：点一个人，他和所有相关的人临时排在一起——他本人在第一列，紧挨着是其他文明的相关人物（按文明分组，关系多的在前），再往右是同一文明的相关人物；时间只取他的一生和各条关系的年份，压缩到人物卡上方的一屏之内，所有连线都看得到。点其中任一人接着看他的关系，卡片上的“返回”回到上一位；点“全图”或关掉卡片，回到进来以前的位置。点事件同理，排的是参与的人。没有关系的人、没有登记参与者的事件不进聚焦，就在长图上滚到它那里。人物卡在聚焦时先只露出一小条，点一下展开。

（2026-11-23 定）原先一次只看一条泳道的一段，跨文明的关系要靠虚线框的“客人”和来回切换，连线常在屏幕外。对比过两种改法：一是点中人物后把相关的文明整条挪到旁边，二是关系聚焦。前者挪的是文明不是人，相关的人仍可能在屏幕外，且每点一人顺序变一次；项目方选了后者。两个可操作的示例留在 `prototypes/links/`（运行 `node prototypes/links/serve.mjs`）。

（2026-11-24）原先分“时代总览”和“人物”两层；加了缩放以后两层合成一张图，项目方定的。

### 2.7 搜索与详情卡（已在示例中验证，2026-11-20）

- **搜索**是一个单独的界面，不用下拉菜单。人物、事件分两栏，各自显示命中数。
  - 不输入时按文明分组列出全部，可以当目录浏览。
  - 输入后按命中程度排序：名字命中在前，身份次之，简介里带到的在后，并显示命中的那半句。
  - 输入时自动切到命中更准的那一栏。
- **详情卡有两种大小**：侧栏（手机上是底部抽屉）和全屏，用“展开全屏”切换。
  - 侧栏：简介、较长的介绍、关系、参与的事件。
  - 全屏多出：生平年表、按类型分组的关系、同时代的其他文明人物、当时各文明所处的时期；事件则多出相关人物当时的年龄、前后的事、前后五年内其他文明的事。
  - 全屏多出的内容都由结构数据算出，不需要另写文字。需要人写的只有“较长的介绍”一项。
- 卡片里的人名、事件名都可以点，一路跳转；左上角有“返回”。

### 2.8 “时期”菜单（2026-11-29，项目方看过示例后同意）

快捷视图越录越多，不再一个个平铺在顶栏。桌面在“概览”旁边放一个“时期 ▾”按钮，手机在图上方小栏的“全貌”旁边放“时期”；点开是分组的菜单，选一项就飞到那一段并展开对应的文明，点别处或按 Esc 收起。

- 菜单里的项目就是 `data/site.yaml` 的 `views`，按每项的 `group` 分组（组名在 `ui.yaml` 的 `viewgroup.<组>`）；与组同名的那一项（如 `china`、`bible`）显示成“全程”。没有 `group` 的视图（`world`）不进菜单。以后每录完一批，照旧加一条视图并写上 `group` 即可。
- 目前三组：中国（全程加 13 段）、圣经与教会历史（全程加 21 段）、希腊与罗马（4 段）。
- **圣经与教会历史的子时期照圣经泳道现有的分期一段一项**（`bible-<分期 id>`，从“太初”到“合一与持守”），名称与泳道色带上的一致，不另起名、不合并；范围取该段前后各放宽约 4%。泳道分期有增改时，这里跟着改。
- 手机上选一项：跳到该视图 `open` 里的第一个文明（没有就是默认展开的文明），缩放到这一段差不多占满一屏。

## 3. 圣经历史与古代史的处理

需求是"古代历史从圣经历史开始"。落地时要解决一个实际问题：**圣经纪年、传统纪年与考古纪年并不总是一致**，中国上古史也有同样的问题（三皇五帝、夏代年代）。方案是不在数据里"选边"，而是把口径标清楚：

- 每个日期都带两项标注：
  - **纪年口径** `scheme`：如 `ussher`（乌雪纪年，创世于公元前 4004 年）、`lxx`（七十士译本纪年）、`xsz`（夏商周断代工程）、`scholarly`（学界通行）。同一事件可以同时记录多种口径下的年份。创世到巴别这一段是例外，见 3.1。
  - **确定度** `certainty`：`attested`（有同时代文献或考古互证）/ `traditional`（传统说法）/ `disputed`（有争议）/ `legendary`（传说）。
- 界面上用样式区分：确凿的画实线，传统说法画虚线，传说时代用淡色，并在图例里说明。
- **泳道安排**：古代部分第一条泳道为"圣经历史 / 以色列"（创世 → 洪水 → 巴别与列国 → 族长 → 出埃及 → 士师 → 王国 → 被掳与归回 → 新约时代），其下依次是两河、埃及、波斯、希腊、罗马，再接中国等。创世记第 10 章的"列国表"可作为从圣经泳道指向各文明泳道的连线。
- 从公元前 9 世纪起（亚述年表、米沙石碑等），圣经记载与外部史料大量互证，两套口径基本合流，之后不再需要区分。
- 中国史同理：公元前 841 年（共和元年）之后为确切纪年；之前的夏、商及五帝时期按上面的方式标注。

这样既能完整呈现圣经叙事，也不会和旁边泳道的年代互相打架，读者始终知道自己看到的是哪一种口径。

### 3.1 创世年代：只排先后，不标年份

项目方的立场：创世年代不能靠把家谱里的岁数简单相加得出；世界的年龄不是几十亿年，但也不会只有六千年那么近。据此：

- **太初部分（创世、洪水、巴别）不上刻度。** 在时间长河里，它画成圣经泳道最左端一段带斜线底纹的区域，标明"只排先后，不标年份"，内部事件只按顺序排列。
- **从亚伯拉罕起上刻度**，标为"传统说法、约数"；从王国时期起为确切纪年。
- 乌雪纪年（创世于前 4004 年）、七十士译本纪年（约前 5500 年）等推算，只在创世条目的详情里作为"历代推算"列出，不作为时间轴的依据。
- 圣经泳道标明"按圣经记载排列"。它与主流科学测年是不同的口径，不混在同一把尺上。

这一立场在解经传统里有依据，可称"家谱间隔说"：

- William Henry Green《Primeval Chronology》（Bibliotheca Sacra，1890）：创世记 5、11 章的家谱不是为推算年代而写，圣经家谱常省略世代（如马太福音第 1 章）。B. B. Warfield（1911）沿用此说。
- John Whitcomb 与 Henry Morris《The Genesis Flood》（1961）：在年轻地球的前提下承认家谱有间隔，把洪水与创世的年代前推数千年，同时反对无限拉长。William Barrick 等人的"有限间隔"说与此相近。（具体数字写进网站前要核对原书。）
- 对立意见：今天主要的年轻地球机构多坚持家谱无间隔、约六千年；Jeremy Sexton 等学者批评 Green 只证明了"可能省略世代"，没有证明"年数不可相加"。

### 3.2 族长到士师：按经文自己的数字倒推（2026-11-21）

圣经泳道从亚伯拉罕起上刻度。王国时期以前没有外部史料可以对照，年份一律按**圣经自己给的数字**从后往前推，全部标“约”：

| 依据 | 推出 |
|---|---|
| 所罗门第四年建殿，约前 966 年；此时距出埃及 480 年（王上 6:1） | 出埃及约前 1446 年 |
| 以色列人住在埃及 430 年（出 12:40） | 雅各下埃及约前 1876 年 |
| 雅各下埃及时 130 岁；以撒 60 岁生雅各；亚伯拉罕 100 岁生以撒（创 47:9、25:26、21:5） | 雅各约前 2006 年生，以撒约前 2066 年生，亚伯拉罕约前 2166 年生 |

- 泳道上几个时期的分界随之调整：太初止于亚伯拉罕出生（约前 2166 年），族长时期止于雅各下埃及（约前 1876 年），寄居埃及止于出埃及（约前 1446 年）。
- 不少学者主张出埃及在前 13 世纪。这一说法写在“出埃及”条目的正文里，不作为时间轴的依据（内容原则第 5 条：以圣经记载为据）。**如果项目方想改用另一种口径，只需要改这张表，各条目的年份跟着平移。**
- 士师时期的人物圣经没有给生卒年，一律标“生卒年不详”，图上只画一段渐隐的条表示大致先后。
- 分国时期诸王取学界常用的蒂勒（Thiele）年表；从前 9 世纪起与亚述、巴比伦的史料互证。
- 分国时期（前 930—前 586 年）的君王和先知用阵营区分颜色：北国以色列为绿（`israel`），南国犹大为紫（`judah`），在详情卡的泳道名后注明。绿、紫与泳道的金色、关系线的红蓝青都分得开，色弱读者也能靠明暗分辨。君王按所统治的国；先知按主要的工作对象（阿摩司是犹大人，主要向北国说预言，归北国）。分国以前和被掳以后的人物不分色。（2026-11-22）
- 耶稣降生取约前 5 年（大希律死于前 4 年之前），受难取约公元 30 年；公元 33 年一说写在正文里。
- 与圣经历史直接相关的外邦君王（西拿基立、尼布甲尼撒、居鲁士、亚达薛西、庞培、彼拉多、提多）放在各自文明的泳道里，用关系线和事件与圣经泳道相连。

### 3.3 中国上古：五帝只排先后，夏商西周取断代工程年表（2026-11-22）

中国泳道公元前 841 年（共和元年）以前没有确切纪年。录入先秦人物时按下面的口径：

| 时段 | 做法 | 图上的样子 |
|---|---|---|
| **五帝传说时代**（黄帝至禹） | 与圣经的太初一样**只排先后、不标年份**：写 `era: five-emperors` 和 `seq`，并标 `certainty: legendary` | 色带画斜线底纹；人物画虚线框，卡片写“只排先后，不标年份”，并注明“传说时代……不当作信史” |
| **夏、商** | 王朝起止取**夏商周断代工程**（2000 年公布）的年表：夏约前 2070—前 1600 年，商约前 1600—前 1046 年，盘庚迁殷约前 1300 年，武丁在位约前 1250—前 1192 年，帝辛约前 1075—前 1046 年。年份标 `circa`、`certainty: traditional`、`scheme: xsz`。断代工程没有给出年代的人（启、少康、桀、汤、伊尹、妇好等）一律“生卒年不详”，只给作图用的大致位置 | 色带画虚线框；人物画虚线框（生卒不详的再加渐隐）；事件画空心菱形；卡片注明“前 841 年以前……是传统说法”“年代取夏商周断代工程的年表，学界有不同意见” |
| **西周**（前 1046—前 841） | 克商取断代工程的前 1046 年，武王、成王、穆王、厉王即位等取断代工程的王年，标法同上；文王、周公、太公、召公生卒不详 | 同上 |
| **共和元年以后** | 确切纪年，不再标传统说法 | 实线 |

- 理由：中国泳道原有的夏、商、西周色带本来就是按断代工程画的（前 2069、前 1599、前 1045 三个界点），人物条目沿用同一口径，图上才对得齐。断代工程的结论在学界有争议（克商之年就有四十多种推算），所以每条都在卡片上注明口径，正文里也写明“断代工程定为……”。
- 禹放在五帝一段的末尾（只排先后），夏朝从启开始有大致位置；“夏朝建立”一事标在约前 2070 年。
- 传说人物和事件的正文一律写“相传”“据《史记》”，有不同记载的（如《竹书纪年》“舜囚尧”“益干启位”）并列写出。
- 如果项目方想换用别的年表（例如《竹书纪年》系统或某位学者的推算），只需改相关条目的年份和 `scheme`，色带的三个界点在 `data/polity/china.yaml`。

## 4. 数据模型

原则：**结构数据与文字分离**。年份、关系、ID 与语言无关，只存一份；名称与描述按语言分文件。这是多语言能低成本扩展的前提。

### 4.1 实体

| 实体 | 说明 | 关键字段 |
|---|---|---|
| `polity` 政权/时代 | 文明 → 时代 → 朝代 → 政权，树状 | `id` `parent` `start` `end` `capitals[{place, start, end}]` `importance` |
| `person` 人物 | 节点 | `id` `birth` `death` `birthplace` `deathplace` `places[]` `reign[]` `polity[]` `roles[]` `importance` `tags[]` |
| `event` 事件 | 点或时间段 | `id` `start` `end` `type` `participants[{person, role}]` `polity[]` `places[]` `importance` |
| `relation` 关系 | 人物之间的边 | `from` `to` `type` `start` `end` `source` |
| `place` 地点 | 从第一条正式数据起就录，见 4.3 | `id` `lat` `lng` `precision` `certainty` `wikidata` |
| `source` 出处 | 每条数据可追溯 | `id` `title` `url` |

关系类型（初版）：亲属（父子、夫妻、兄弟、祖孙）、政治（君臣、继位、政敌、同盟）、学术（师生、同门、思想影响）、军事（对手、同袍）、交游（友人、唱和、举荐）。

### 4.2 日期

```yaml
birth:
  year: -230          # 天文纪年：公元前 231 年记为 -230（公元前 1 年 = 0），便于计算
  precision: year     # year | decade | century
  circa: true         # 是否为"约"
  certainty: disputed
  scheme: scholarly
  original: "秦王政十六年"   # 原始纪年写法，可选
```

内部一律用天文纪年整数，显示时再转换成"公元前 231 年"；避免"没有公元 0 年"带来的计算错误。

两种特殊情况：

- **确定度与口径**：`certainty`、`scheme` 可以写在每个年份里（`birth: { year: -1249, circa: true, certainty: traditional, scheme: xsz }`），也可以写在整条上。任一年份是 `traditional` 或 `legendary` 的，网站把人物条画成虚线框、事件画成空心菱形，详情卡在年份下面注明口径（见 3.3）。批量导入时用 `cert:`、`sch:` 两个键，见 `scripts/import-batch.mjs` 文件头。
- **只排先后、不标年份**（太初，见 3.1；中国的五帝传说时代，见 3.3）：人物、事件不写年份，写 `era: primeval`（或 `five-emperors`）和先后次序 `seq`（人物是 `[起, 止]`，事件是一个数）。网站按次序把它们均匀排在那一段带斜线的色带里，条画成虚线框，所有显示年份的地方都写“只排先后，不标年份”，详情里也不算年龄、不列“同时代的人”。
- **史料明确记载的高寿**（如亚伯拉罕 175 岁、摩西 120 岁）：加 `long_life: true`，否则校验脚本会把超过 110 岁的寿命当成录入错误。

### 4.3 地点

地图功能排在时间长河之后（见第 8 节 P5），但**地点从第一条正式数据起就录**（2026-11-20 确定）。录一条人物或事件时顺手记地点几乎不费事；等几千条录完再回头补，等于把每条数据重查一遍。

录什么：

- **人物**：`birthplace` 出生地、`deathplace` 去世地；`places[]` 记主要活动地（任职、封地、征战、流放等），可带起止年。
- **事件**：`places[]` 发生地，至少一个。战役、会盟、建都这类事件必须有。
- **政权**：`capitals[]` 都城，带起止年（都城会迁）。

怎么录：

1. **填地点的 ID，不填文字。** 同一个地方只建一条 `place`，所有人物和事件都指向它。日后做地图时，“这个地方发生过什么、出过什么人”直接就能查出来。
2. **查不到就写 `unknown`，不要留空。** 留空表示“还没查”，`unknown` 表示“查过了，史料没有记载”。校验脚本对留空的给出提醒。
3. **录入时只要求三样：古地名、今地、精确度。** 经纬度可以后补：每个地点挂 Wikidata 编号，日后批量取坐标。不要为了填坐标而估一个数。
4. **精确度 `precision`**：`site`（具体地点，如某座宫殿、某处战场）/ `city`（城邑、县）/ `region`（只知道大致区域，如“漠北”）。地图上按精确度画成点或一片范围。
5. **确定度 `certainty`**：沿用 4.2 的四档。地望有争议的（如垓下）标 `disputed`，另一说写在文字里。
6. **古今地名**：同一个地方历代的名称写在语言文件的 `names[]` 里并带起止年（长安、大兴、西安是同一条）。只有位置确实不同的才另建一条。
7. **坐标一律存 WGS-84**（国际通用的经纬度）。国内地图服务使用加偏坐标，显示时再转换，不写进数据。

```yaml
# data/place/gaixia.yaml            —— 结构，语言无关
id: gaixia
wikidata: Q…                        # 录入时查实并填写
lat: …                              # 可后补；查实再填，不要估
lng: …
precision: site
certainty: disputed
```

```yaml
# locales/zh-CN/place/gaixia.yaml   —— 文字，每种语言一份
name: 垓下
modern: 安徽省灵璧县东南              # 今地，录入时必填
note: 一说在今安徽省固镇县。
```

### 4.5 数据来源与质量

- **Wikidata / 维基百科**：生卒年、译名、基本关系；授权宽松（CC0 / CC BY-SA）。
- **CBDB 中国历代人物传记数据库**（哈佛）：数十万人物的亲属与社会关系，是"人物关联"最好的来源；其授权为 CC BY-NC-SA；本项目非商用，可以使用，但须署名，且由它衍生的数据要以相同方式授权。
- **中国历代纪元表**、二十四史：帝王年号与在位年代核对。
- **地点**：中国历代地名与坐标可查 CHGIS（中国历史地理信息系统，复旦大学与哈佛大学合作）；CBDB 的地址表也带坐标；古代地中海与近东可查 Pleiades；通用坐标取自 Wikidata。CHGIS 与 Pleiades 的授权条款，使用前要核实。
- 录入流程：AI 起草 → 人工核对 → 标记 `reviewed: true`。每条记录保留 `source`。构建时用校验脚本检查（卒年不早于生年、关系两端 ID 存在、人物年代落在所属政权范围内、引用的地点 ID 存在、事件有地点或已标 `unknown` 等）。

### 4.6 十六国人物放在哪条泳道（2026-11-21）

十六国的君主多出自匈奴、羯、鲜卑、氐、羌，但**一律放在中国泳道**（`civ: china`），不放“草原”泳道。理由：

- 这些政权都建在中原、关中、河北、蜀地，都城是平阳、襄国、邺、长安、成都这些中国城市，用的是中原的官制和年号，对手和盟友是晋朝；它们的历史在正史里写作《晋书·载记》，是中国史的一部分。中国泳道这一段的名称本来就是“东晋十六国”。
- “草原”泳道留给始终以漠南漠北为根据地的游牧政权（匈奴、鲜卑檀石槐、柔然、突厥等）。拓跋珪的代国起于塞北，但他在 398 年迁都平城、称帝建魏，此后是北朝的开端，所以也放在中国泳道。
- 放在同一条泳道里，淝水之战、刘裕北伐这类南北之间的事件和连线才不必跨泳道，手机上（一次只看一条泳道）也能完整看到。

**派别按政权分**，同一家族前后相承的并为一个，免得颜色太碎：`hanzhao` 汉赵（刘渊的汉与刘曜的前赵）、`houzhao` 后赵与冉魏、`chenghan` 成汉、`yan` 慕容燕（前燕、后燕）、`qianqin` 前秦、`houqin` 后秦、`xia` 胡夏、`beiwei` 代与北魏；另有 `sunlu` 孙恩卢循、`liusong` 刘宋（刘裕归此，南朝部分接着用）。西晋、东晋都用已有的 `jin`。

几个要说明的归属：桓玄虽一度称楚帝，为时不到半年，仍归 `jin`；冉闵是石虎的养孙，归 `houzhao`；僧人按主要活动的政权归类（佛图澄归后赵，鸠摩罗什归后秦，道安、慧远、法显归晋）。前凉、后凉、西秦、南燕、北燕等这一批没有单列人物，只在正文里提到，以后补录时再加派别。

**南北朝（2026-11-22 补）**沿用同一思路，北朝人物同样放在中国泳道，派别仍按政权分，同一家族前后相承的并为一个：南朝 `liusong` 刘宋、`nanqi` 南齐、`liang` 萧梁、`chen` 陈；北朝 `beiwei` 代与北魏（到 534 年分裂为止），`beiqi` 东魏与北齐（东魏实权在高欢父子手里，北齐由高洋篡东魏而来，所以合为一个），`beizhou` 西魏与北周（同理，实权在宇文泰一家）；另加 `sui` 隋，杨坚归此。

- **柔然**放在“北方草原”泳道（`civ: steppe`，派别 `rouran`），理由同上：它始终以漠北为根据地，草原泳道本来就有“柔然”一段。突厥灭柔然一事也放在草原泳道。吐谷浑这一批没有单列人物。
- **跨朝代的人**按主要事迹所在的政权归类：祖冲之归刘宋（《大明历》作于宋），范缜归南齐（《神灭论》之争在齐），沈约、刘勰、钟嵘、陶弘景归萧梁，徐陵、智顗归陈，庾信归北周（后半生在北方，代表作写于北方），颜之推归北齐。
- **侯景**归 `beiqi`：他前半生是尔朱荣、高欢的部将，叛东魏投梁后在江南作乱，称帝不到半年，与桓玄归 `jin` 是同样的处理。
- 僧人仍按主要活动的政权归类：寇谦之、昙曜、达摩归北魏。

**隋与唐前期（2026-11-22 补）**仍按同一思路，派别按政权分，人物尽量留在中国泳道，只有始终以别处为根据地的政权才放到别的泳道：

- **派别**：隋用已有的 `sui`；`suimo` 隋末群雄（窦建德、李密、王世充——这些割据者先后称王称帝，为时都只有几年，合为一个，免得颜色太碎）；`tang` 唐；`anshi` 安史（大燕），目前只有安禄山，下一批的史思明等人接着用。宇文化及弑君后虽然称帝，前半生是隋朝的将领，归 `sui`。
- **武周不单列**，武则天归 `tang`。武周只有十五年（690—705），前后的人物都是唐朝的臣子；武则天在称帝前已经以皇后、太后的身份执政三十多年，退位后国号又恢复为唐。与桓玄归晋、侯景归北齐是同样的处理。
- **突厥**放在“北方草原”泳道（`civ: steppe`，派别 `tujue`），理由同柔然：东突厥、后突厥始终以漠南、漠北为根据地。“后突厥复国”放草原泳道；“唐灭东突厥”“唐灭西突厥”是唐朝发动的战争，放中国泳道。
- **吐蕃**放在中国泳道，派别 `tubo`。网站目前没有青藏高原的泳道；这一批的吐蕃人物（松赞干布、禄东赞）的事迹都与唐朝有关，史料主要是两《唐书》的《吐蕃传》；放在同一条泳道里，文成公主与松赞干布的连线不必跨泳道，手机上也能完整看到。日后如果增设青藏高原或内亚的泳道，只需改这两人的 `civ`。
- **高句丽、新罗**放在“朝鲜半岛”泳道（`civ: korea`，派别 `gaogouli`、`xinluo`）；阿倍仲麻吕和“遣隋使”“遣唐使”两件事放在“日本”泳道。这两个文明本来就有自己的泳道，与隋唐的往来用关系线和跨泳道的事件表现。“白江口之战”发生在朝鲜半岛，交战一方是倭国，放朝鲜半岛泳道。高仙芝是高句丽人，但一生在唐军中，归 `tang`。
- **跨朝代的人**按主要事迹归类：苏威由隋入唐，事迹主要在隋，归 `sui`；魏征、李勣、孔颖达、李靖等隋末唐初的人归 `tang`；僧人鉴真、一行、慧能、玄奘归 `tang`。
- **终点**取在安史之乱爆发（755 年）。一生跨过 755 年的人（唐玄宗、李白、杜甫、王维、鉴真、高力士等）都写完全传；“安史之乱”一条概述了 755—763 年的全过程，郭子仪、李光弼、颜真卿、史思明、唐肃宗等人留待下一批补录。

**唐后期（2026-11-22 补）**，从安史之乱爆发（755 年）录到唐亡（907 年），仍按同一思路：

- **派别**：唐朝君臣仍用 `tang`，安史一方仍用 `anshi`（史思明、安庆绪、史朝义），吐蕃仍用 `tubo`。新增 `fanzhen` 割据藩镇（田承嗣、朱泚、李希烈、吴元济——这些人各据一方、时叛时降，单独每人一个颜色太碎，合为一个）；`tangmo` 唐末民变（庞勋、王仙芝、黄巢）；`houliang` 后梁（朱温）、`shatuo` 沙陀（晋）（李克用），这两个派别是为五代预留的，下一批的朱友珪、李存勖等人接着用。朱温、李克用的主要事迹虽在唐末，但他们各自开创的政权延续到五代，按“开创者归其政权”处理，与杨坚归隋相同。
- **割据藩镇与唐朝节度使的分界**：只有公开抗命、自立或称帝的才归 `fanzhen`；仆固怀恩虽然后来反叛，但一生主要是平定安史的唐将，归 `tang`；高骈晚年不听调遣，但没有公开反叛，也归 `tang`。
- **回纥（回鹘）**放在“北方草原”泳道（`civ: steppe`，派别 `huihe`），理由同突厥：始终以漠北为根据地，草原泳道本来就有“回纥”一段（744—840）。“回鹘汗国瓦解”放草原泳道。
- **南诏**放在中国泳道（派别 `nanzhao`），理由同吐蕃：网站目前没有西南的泳道，“越南与东南亚”泳道也不合适；南诏的史料主要是两《唐书》的《南蛮传》和樊绰《蛮书》，异牟寻的事迹都与唐朝、吐蕃有关。
- **吐蕃王朝崩溃、长庆会盟**放中国泳道（与吐蕃人物同泳道）；圆仁、空海放在“日本”泳道，不设派别，与阿倍仲麻吕相同。
- **跨朝代的人**：韦庄晚年任前蜀宰相，但《秦妇吟》等主要事迹在唐末，归 `tang`；朱温卒于 912 年、李克用卒于 908 年，都写完全传。
- **终点**取在唐亡（907 年）。安史之乱一条（755—763）是上一批写的，本批没有改动，只补了睢阳之战、收复两京、相州之战等分条。

**先秦（2026-11-22 补）**同样按政权分派别，但春秋战国小国太多，只给事迹多的国家单列：`wudi` 五帝传说（黄帝至舜）、`xiachao` 夏（禹归此）、`shang` 商、`zhou` 周王室（西周诸王、东周的平王与赧王、周公、召公）、`qi` 齐（姜齐、田齐合为一个；姜太公归此）、`jinguo` 晋、`chu` 楚（沿用秦末的“反秦与楚”这一派别，同一颜色）、`qin` 秦（沿用已有的“秦廷”）、`wuguo` 吴、`yueguo` 越、`weiguo` 魏、`zhao` 赵（赵襄子起）、`hanguo` 韩、`yanguo` 燕；郑、宋、鲁、卫等小国并为 `zhuhou`（郑宋鲁等国）；孔子及弟子、老子、墨子、孟子、庄子、惠施、荀子、韩非归 `zhuzi`（诸子），即使他们做过某国的官。已有的 `xia`（胡夏）、`jin`（晋朝）、`wei`（曹魏）、`han`（汉）、`yan`（慕容燕）、`wu`（孙吴）都是后世政权，先秦的同名国家另起 id，免得颜色混用。几个归属：吴起事迹分在魏、楚两国，归 `weiguo`；苏秦为燕昭王做反间，归 `yanguo`；张仪、范雎、吕不韦、李冰归 `qin`；孙膑、田忌归 `qi`。终点取在前 262 年样板时段开始前后，长平之战（前 260 年）、邯郸之战（前 257 年）、秦灭西周（前 256 年）一并录入；白起、范雎、平原君、信陵君、春申君、荀子、韩非、吕不韦等跨入样板时段的人也写了全传，并与秦始皇、李斯连线。

**五代十国（2026-11-22 补）**，从唐亡（907 年）录到陈桥兵变（960 年），仍按同一思路：

- **派别**：五代沿用唐后期预留的 `houliang` 后梁和 `shatuo`，后者的名称改为“沙陀（晋、后唐）”，李克用、李存勖、李嗣源、李从珂都归此（晋与后唐是同一家族前后相承）；新增 `houjin` 后晋、`houhan` 后汉与北汉（北汉是刘知远之弟刘崇所建，同一家族，合为一个）、`houzhou` 后周、`songchao` 宋（赵匡胤、赵普，下一批北宋接着用）。后晋、后汉的开国者虽然也出自沙陀，但三朝互相攻伐，合为一色反而看不出更替，所以分开。十国按“颜色不要太碎”合并为三个：`nantang` 吴与南唐（杨行密、徐温、李昪一脉相承：李昪是徐温的养子，受吴禅让）、`qianhoushu` 前蜀与后蜀（两个王朝都据成都、先后相接）、`nanfang` 南方诸国（吴越、闽、楚、南汉、荆南——这几国在本批各只有一两位人物）。唐末延续下来的燕（刘守光）、岐（李茂贞）归唐后期已有的 `fanzhen` 割据藩镇。
- **契丹（辽）放在“北方草原”泳道**（`civ: steppe`，派别 `qidan`），理由同突厥、回纥：契丹兴起于潢水、土河流域，皇都临潢府（上京）在今内蒙古赤峰，耶律阿保机、述律后、耶律德光始终以草原为根据地，燕云十六州是后来取得的；《辽史》也自成一部，不在五代史之内。草原泳道原来的“诸部并立”（840—1206）一段相应拆成三段：诸部并立（840—916）、辽（契丹）（916—1125）、诸部并立（1125—1206），让泳道上的名称与人物对得上。契丹建国、契丹文字创制、契丹灭渤海三件事放草原泳道；石敬瑭割燕云十六州、后晋灭后唐、契丹灭后晋发生在中原、主角是中原君臣，放中国泳道，用关系线（耶律德光与石敬瑭、石重贵、冯道等）连到草原泳道。
- **跨朝代的人**按主要事迹归类：冯道历仕四朝，主持雕印九经、出任宰相都始于后唐明宗时，归 `shatuo`；和凝、刘昫的主要事迹（任宰相、进呈《旧唐书》）在后晋，归 `houjin`；杨凝式历仕五朝，事迹以晚年在洛阳的书迹为主，归 `houzhou`；范质由后周入宋，顾命辅政在后周，归 `houzhou`；荆浩、关仝主要活动在后梁时期，归 `houliang`；画家、词人按所在的国家归 `nantang`、`qianhoushu`；韩延徽、耶律倍归 `qidan`。
- **终点**取在陈桥兵变（960 年），即五代结束、北宋建立。十国中有六国延续到 960 年以后（荆南 963、后蜀 965、南汉 971、南唐 975、吴越 978、北汉 979 年亡于北宋），这些国家的君主（孟昶、李煜、钱俶等）都写完全传，亡国的经过写在人物正文里，“宋灭后蜀”“宋灭南唐”“北汉灭亡”等事件留给北宋那一批。赵匡胤以 960 年以前的事迹为主，960 年以后只在末段简述。

**北宋（2026-11-22 补）**，从陈桥兵变之后（960 年）录到靖康之变（1127 年），仍按同一思路：

- **派别**：北宋君臣、文人都用五代那一批预留的 `songchao` 宋，不再按新旧党分色——新旧两党是同一朝廷里的政见之争，人物又常常前后转向（如蔡京先附旧党、后为新党），分色反而误导；党派归属写在正文和关系线里。新增 `xixia` 西夏（李继迁、李元昊）、`jinchao` 金（完颜阿骨打、金太宗、完颜宗翰、完颜宗望、完颜希尹）、`songmin` 北宋民变（方腊；王小波、李顺、宋江只有事件，没有单列人物）。“金”另起 id，免得与已有的 `jin`（晋朝）、`jinguo`（先秦晋国）、`houjin`（后晋）混用。辽朝人物（萧绰、辽圣宗、耶律休哥、天祚帝、耶律大石）继续用 `qidan`。
- **辽仍在“北方草原”泳道**，理由见上一段；“金灭辽”“耶律大石西行与西辽建立”两件事也放草原泳道，草原泳道上“辽（契丹）”一段到 1125 年为止，正好与金灭辽对上。西辽在中亚，网站没有中亚泳道，暂时随辽放在草原泳道。
- **西夏放中国泳道**，理由同吐蕃、南诏：网站没有西北或内亚的泳道；西夏的都城兴庆府在今宁夏银川，统治区域是今宁夏、甘肃、陕北，用汉式官制和年号；它的史料主要在《宋史·夏国传》《辽史·西夏外纪》里，事迹几乎都与宋朝的战与和有关。放在同一条泳道里，李元昊与范仲淹、韩琦、狄青的连线不必跨泳道，手机上也能完整看到。
- **金也放中国泳道**，不放草原泳道。女真兴起于按出虎水（今黑龙江阿城一带），以渔猎和农耕为生，不是游牧民族，草原泳道的“诸部并立”（1125—1206）一段也装不下它；金朝从起兵到灭北宋只有十三年，此后一百多年都统治华北，迁都燕京、开封，与南宋对峙，它的历史与中国泳道上的南宋是一体的。这样靖康之变、海上之盟这些宋金之间的事件和连线都在一条泳道上。“金建国”是女真内部的事，但金朝其后的历史在中国泳道，所以一并放中国泳道。日后如果增设东北或内亚的泳道，只需改这几位人物和事件的 `civ`。
- **跨朝代的人**：李纲、李清照、宋钦宗、金太宗、完颜宗翰、完颜希尹、耶律大石的主要事迹或后半生在 1127 年以后，都写完全传，归属按本批的派别；李成卒于 967 年，主要活动在五代，但他的画名、影响都在北宋，归 `songchao`；张邦昌虽被金朝立为“楚帝”，为时三十多天，与桓玄归晋同样处理，归 `songchao`。
- **终点**取在靖康之变（1127 年四月金军押徽、钦二帝北撤）为止。赵构五月在南京应天府即位、南宋开始，留给南宋那一批；宗泽、岳飞、韩世忠等人也留给南宋那一批。

**南宋、金、蒙古与元（2026-11-22 补）**，从靖康之变之后（1127 年宋高宗即位）录到元朝退出中原、明朝建立（1368 年）：

- **派别**：南宋君臣、文人继续用 `songchao` 宋；金朝继续用 `jinchao` 金（伪齐的刘豫是金朝扶立、与南宋为敌的傀儡皇帝，归 `jinchao`；与只当了三十多天“楚帝”的张邦昌不同）。新增 `menggu` 蒙古（大蒙古国时期的大汗、宗王、将领和耶律楚材）、`yuanchao` 元（忽必烈及元朝君臣、文化人物）、`yuanmo` 元末群雄（韩山童、刘福通、郭子兴、张士诚、陈友谅）、`mingchao` 明（朱元璋、徐达、刘基，下一批明朝接着用；与五代那一批为赵匡胤预留 `songchao` 同理）。
- **蒙古帝国前期放“北方草原”泳道**（`civ: steppe`）：成吉思汗、窝阔台、拖雷、蒙哥、拔都、速不台、木华黎、阿里不哥以及耶律楚材。理由同辽、突厥：大蒙古国起于斡难河、以哈拉和林为都城，大汗始终坐镇漠北，统治的是横跨亚欧的帝国，中原只是其中一部分；草原泳道原本就有“蒙古帝国”一段（1206—1368）。耶律楚材虽然主管汉地事务，但他任职于和林的大汗朝廷、死于和林，所以随大汗归草原泳道。“大蒙古国建立”“蒙古第一次西征”“蒙古第二次西征”“忽必烈与阿里不哥争位”放草原泳道。
- **忽必烈及元朝放中国泳道**（`civ: china`）。理由同拓跋珪：忽必烈 1260 年在开平即位后采用汉法、建元中统，1271 年定国号“大元”，以大都为都城，统治重心转到汉地，其后的元朝与中国泳道上的南宋、明朝前后相接；中国泳道原本就有“元”一段（1279—1368）。蒙古攻打金、西夏、南宋、大理的战争（野狐岭之战、金宣宗南迁、蒙古灭金、蒙古灭西夏、端平入洛、蒙古灭大理、钓鱼城之战）发生在中原和西南，用关系线连到草原泳道上的大汗。蒙哥死于钓鱼城下，人物仍在草原泳道。
- **别的泳道**：旭烈兀放“两河与波斯”泳道（他在波斯建立伊利汗国，那条泳道上“阿拉伯帝国”一段到 1258 年为止，正好与“巴格达陷落”对上），派别仍是 `menggu`；北条时宗放日本泳道；马可·波罗放“罗马与欧洲”泳道。“元军征日本”是元朝发动的战争，放中国泳道，用关系线连到北条时宗。
- **跨朝代的人**：宋高宗在北宋那一批没有单列，本批写了完全传；李纲、宋钦宗、金太宗、李清照等跨靖康的人，北宋那一批已经写了完全传，本批只连线（宋高宗与宋徽宗、宋钦宗、李纲，完颜宗弼与金太祖、完颜宗望等）；朱元璋、徐达、刘基、扩廓帖木儿的后半生在 1368 年以后，写了完全传，1368 年以后的事迹在末段简述；元顺帝 1370 年死于应昌，也写完全传。
- **终点**取在 1368 年八月徐达攻入大都。北元、明初诸事留给下一批。中国泳道上“南宋与金”一段（1127—1279）、“元”一段（1279—1368）的分界本批没有动；按这个分界，1271 年的“元朝建立”画在“南宋与金”一段里，“元朝建立”条的正文里写明了元朝起点有 1260、1271、1279 年三种算法。

**明清（2026-11-22 补）**，从明朝建立之后（1368 年）录到清帝退位（1912 年），分明、清前期（至 1799 年乾隆帝去世）、晚清三批：

- **派别**：明朝君臣、文人继续用 `mingchao` 明；新增 `mingmo` 明末民变（李自成、张献忠，与 `tangmo`、`yuanmo` 同理）、`qingchao` 后金与清（努尔哈赤、皇太极及清朝君臣、文人）、`nanming` 南明与明遗民（史可法、郑芝龙、郑成功、永历帝、李定国，以及黄宗羲、顾炎武、王夫之——三人都曾参加抗清、入清不仕，归入清朝不合他们的立场，单列一色又太碎，所以与南明并为一个）、`taiping` 太平天国、`geming` 革命党（孙中山、黄兴、秋瑾、宋教仁，以及武昌起义后被推为都督的黎元洪）。清朝不再按“维新”“洋务”分色：康有为、梁启超、谭嗣同的变法是在清廷内部推行的，与北宋新旧党不分色同理；袁世凯在 1912 年以前是清朝的重臣，也归 `qingchao`，民国以后的事迹只在正文末段简述。吴三桂受清朝封爵三十年，三藩之乱时称帝不到半年，与桓玄归晋同样处理，归 `qingchao`；洪承畴降清后为清朝经略南方，也归 `qingchao`。
- **后金与清入关前放中国泳道**（`civ: china`），理由同金朝：建州女真以赫图阿拉、辽阳、沈阳为根据地，以农耕和渔猎为生，不是草原游牧政权；后金（1616）与此后的清朝是同一政权前后相承，1636 年改国号、1644 年入关，此后统治中国二百六十多年，放在同一条泳道里，萨尔浒、宁远、己巳之变、松锦之战这些明清之间的事件和连线就不必跨泳道。所以“后金建立”（1616）、“皇太极改国号大清”（1636）画在“明”一段里，清朝的色带仍从 1644 年开始，没有改动时期划分。日后如果增设东北或内亚的泳道，只需改这几位人物和事件的 `civ`。
- **别的泳道**：瓦剌的也先、土默特的俺答汗放“北方草原”泳道，派别沿用 `menggu`（草原泳道这一段名为“蒙古诸部”，1368—1691）；准噶尔的噶尔丹放“北方草原”泳道，新增派别 `zhunger`。“康熙亲征噶尔丹”“平定准噶尔”是清朝发动的战争，放中国泳道。传教士利玛窦、汤若望、南怀仁、郎世宁、马礼逊、戴德生放圣经泳道（与方济各·沙勿略一致），“利玛窦入华”“礼仪之争”两件事也放圣经泳道；马戛尔尼、赫德放“罗马与欧洲”泳道；丰臣秀吉、伊藤博文放日本泳道；李舜臣放朝鲜半岛泳道。这些人物都不设派别。
- **年份**：用公历年，农历年末的事按公历跨年标注，如嘉靖帝卒于嘉靖四十五年十二月（1567 年 1 月）、戚继光卒于万历十五年十二月（1588 年 1 月）、王守仁卒于嘉靖七年十一月（1529 年 1 月）、孝庄太后卒于康熙二十六年十二月（1688 年 1 月）、同治帝卒于同治十三年十二月（1875 年 1 月）、清帝退位诏书颁于宣统三年十二月二十五日（1912 年 2 月 12 日）。不详或有异说的标约数或“不详”：建文帝下落不明（卒年不详）；郑和卒年约 1433；严嵩卒年约 1567（一说次年）；丰臣秀吉生年约 1537（一说 1536）；史可法生年约 1601（一说 1602）；曹雪芹约 1715—约 1763（卒年另有 1764 之说）；罗贯中、吴承恩、宋应星、杨秀清、冯云山等生年或卒年都标约数或不详。
- **地点**：明清的北京新建地点 `beijing`（北京），不沿用元朝的 `dadu`（大都）。明清北京是在大都的基础上改建的，北城墙南移、南城墙南拓，又加筑外城，与大都并不完全重合；更主要的是卡片上会显示“生于大都”“卒于大都”，放在明清人物身上会误导读者。南京（应天、天京）沿用 `jianye`，扬州沿用 `guangling`，广州沿用 `panyu`，绍兴沿用 `shanyin`，福州（侯官）沿用 `fuzhou-fj`。
- **终点**取在 1912 年 2 月 12 日清帝退位，“中华民国成立”（1912 年 1 月 1 日）也已录入；溥仪、孙中山、袁世凯、康有为、梁启超、严复等跨入民国的人写了完全传，1912 年以后的事迹在末段简述。

### 4.7 欧洲历史怎么录（2026-11-28）

欧洲原来只有时期色带和为圣经、教会史配套录的零星人物（希腊泳道 6 人，“罗马与欧洲”泳道 62 人）。从这一天起按中国史的做法分批补全，项目方确认的口径如下：

- **泳道不拆。** 古希腊在“希腊”泳道（到前 146 年为止），其后都在“罗马与欧洲”一条泳道里；英、法、德、俄等国不各开泳道，像十六国、南北朝那样按国家分派别（颜色），小国并为一色。理由：百年战争、拿破仑战争这类国与国之间的事件和连线不必跨泳道；手机上也不会多出七八列。拜占庭、俄国放欧洲泳道；奥斯曼放“两河与波斯”泳道（萨拉丁已在那里）；波斯诸王（大流士、薛西斯等）放“两河与波斯”泳道，用关系线和事件与希腊泳道相连。教皇、改教家、神学家已在圣经泳道，不重复录，只连线。
- **分 12 批**，每批约 60—75 人、30—40 件事：①古希腊（爱琴文明至苏格拉底之死）②亚历山大与希腊化 ③罗马王政与共和 ④罗马帝国（至 476 年）⑤中世纪早期（476—1000）⑥中世纪盛期（1000—1300）⑦中世纪晚期（1300—1453）⑧文艺复兴与大航海（1453—1648）⑨启蒙与革命（1648—1815）⑩工业时代（1815—1914）⑪两次世界大战 ⑫战后。
- **先录到 1914 年**，与中国泳道止于 1912 年对齐。第 ⑪、⑫ 批**暂缓**：二十世纪涉及在世人物和评价口径，做到那里时再与项目方单独商量。
- **译名用通行译法**（参照《世界人名翻译大辞典》一系的写法，如尤利安、阿拉里克），教会史书里的译法（犹利安、亚拉里克）写进 `aliases`，搜索两种都能找到。已有条目的 `id` 不改，只改 `name`，做到罗马帝国那一批时统一处理。圣经里出现的波斯王，通行译名作正式名称，和合本译名（大利乌、亚哈随鲁）作别名。
- **不指定主线用书**，由 AI 按通行的通史框架选人选事；文字凭训练记忆写，书目进 `recalled`，口径同内容原则第 1 条。
- **年代**：特洛伊战争、荷马、吕库古、第一届奥林匹亚竞技会、罗马建城等，标 `certainty: traditional`（画虚线框、空心菱形），正文写“相传”“传统上定在”；希腊从前 6 世纪起、罗马从共和中期起为确切纪年。古典作家生卒年多为约数，照实标 `circa` 或“不详”。
- **希腊泳道的派别**：`athens` 雅典、`sparta` 斯巴达，其余城邦和各地的诗人、学者并为 `greek-cities`（希腊诸邦）。人物按所属城邦归类，不另设“学者”一色：苏格拉底、索福克勒斯这些雅典公民本来就在雅典的政治和战争里；到雅典讲学的外邦人（阿那克萨戈拉、普罗泰戈拉、希罗多德）仍归 `greek-cities`。波斯诸王不设派别，与已有的居鲁士二世一致。
- **第 ② 批（亚历山大与希腊化）新增的派别与归属**（2026-11-28）：
  - 新增 `thebes` 底比斯：前 371—前 362 年它是希腊的霸主，伊巴密浓达、佩洛皮达斯与雅典、斯巴达三方对阵，并入“希腊诸邦”就看不出来。
  - 新增 `macedon` 马其顿与继业者：腓力二世、亚历山大及其部将，以及留在欧洲的安提柯王朝诸王（安提柯一世、德米特里一世、卡山德、利西马科斯、安提柯二世、三世）同为一色。继业者前期彼此的阵营变换太快，不再细分。已有的腓力五世、珀尔修斯当初没有标派别，经项目方同意已补上 `macedon`（2026-11-28）。
  - 按地域分泳道，不按血统：托勒密诸王和阿尔西诺伊二世放埃及泳道，塞琉古诸王和波斯诸王放“两河与波斯”泳道，旃陀罗笈多、波罗斯放印度泳道，都不设派别（与已有的托勒密二世、安条克三世一致），用关系线和事件与希腊泳道相连。事件同理：高加米拉、波斯波利斯、巴比伦分封在“两河与波斯”，亚历山大城建城、博学园在埃及，希达斯皮斯河、塞琉古与旃陀罗笈多订约在印度，皮洛士战争在“罗马与欧洲”；总括性的“亚历山大东征”“继业者战争”放希腊泳道。
  - 伊庇鲁斯（皮洛士）、叙拉古（狄奥尼修斯一世、提摩勒昂、阿伽托克勒斯、希伦二世）、帕加马（阿塔罗斯一世）、亚该亚同盟（菲洛皮门）以及各地学者仍归 `greek-cities`；为波斯效力的希腊人门农也在其中。入侵希腊的高卢首领布伦努斯放“罗马与欧洲”泳道，起初不设派别，第 ③ 批新增“高卢人”一色后已补上 `gaul`（2026-11-28，经项目方同意）。
  - 归属照第 ① 批的规矩按城邦：伊壁鸠鲁是雅典公民，归 `athens`；亚里士多德、提奥弗拉斯托斯、芝诺是在雅典讲学的外邦人，归 `greek-cities`。欧几里得起初放在希腊泳道，与已有的埃拉托色尼（埃及泳道）口径不一致；经项目方同意改放埃及泳道、不设派别（2026-11-28）：在亚历山大城工作的学者一律按地域归埃及泳道。
  - 重名的处理：`alexander-3` 是教皇亚历山大三世、`philip-2` 是西班牙的腓力二世、`menander` 是印度的米南德一世、`demosthenes-general` 是前 5 世纪的将军，所以亚历山大大帝是 `alexander-great`，马其顿的腓力二世是 `philip-2-macedon`，喜剧诗人是 `menander-poet`，演说家是 `demosthenes`；雅典的吕库古是 `lycurgus-athens`，卡狄亚的欧迈尼斯是 `eumenes-cardia`，入侵希腊的布伦努斯是 `brennus-delphi`（为日后攻入罗马的那位留出 `brennus`）。
- **第 ③ 批（罗马王政与共和）的派别与归属**（2026-11-28）：
  - **罗马人内部不分色。** 贵族派/平民派是近代学者的概括，不是当时的党派；恺撒党、庞培党之类的阵营又换得太快（庞培先是苏拉的部将，再是恺撒的盟友和女婿，最后为元老院领兵；屋大维与安东尼先结盟后决战；西塞罗、雷必达都换过边），硬分两色反而误导，这与第 ② 批对继业者不再细分是同一个道理。谁与谁为敌、为友，由关系线和事件表达。已有的大西庇阿、费边、老加图、庞培等罗马人原来也没有派别，保持一致。
  - **外族各设一色，按地域放泳道，不按血统。** 新增 `italians` 意大利诸族（伊特鲁里亚的波尔塞纳、萨莫奈的庞提乌斯、同盟者战争中的马尔西人波派迪乌斯·西洛，小族并为一色，同“希腊诸邦”的做法）、`gaul` 高卢人（攻入罗马的布伦努斯、维钦托利）、`numidia` 努米底亚（马西尼萨、朱古达；北非与已有的迦太基一样放“罗马与欧洲”泳道）。汉尼拔之弟哈斯德鲁巴归已有的 `carthage`。斯巴达克斯是色雷斯人，但一生的事迹都在意大利，放“罗马与欧洲”泳道，不设派别。
  - 本都的米特里达梯六世、亚美尼亚的提格兰二世放“两河与波斯”泳道，不设派别：小亚细亚和亚美尼亚的王国历来归这条泳道（吕底亚的克洛伊索斯已在那里），也与塞琉古诸王不设派别一致。帕提亚将领苏雷纳放同一泳道，归已有的 `parthia`（安息）。克娄巴特拉七世放埃及泳道，不设派别，与托勒密诸王一致。
  - 事件同理：卡莱战役在美索不达米亚，放“两河与波斯”泳道；托勒密王朝灭亡放埃及泳道；米特里达梯战争是罗马一方的总括性战争，战场又遍及希腊和小亚细亚，放“罗马与欧洲”泳道（同皮洛士战争）。
  - 年代：罗马建城、王政七王、卢克蕾提亚、布鲁图、波尔塞纳、科里奥拉努斯、辛辛纳图斯、十人委员阿庇乌斯、卡米卢斯、布伦努斯、李锡尼·斯托洛，以及建城、共和国建立、平民撤离、十二表法、攻陷维爱、高卢人洗劫罗马、李锡尼—塞克斯提乌斯法，标 `certainty: traditional`；从前 4 世纪后期的拉丁战争、萨莫奈战争起为确切纪年。
  - 重名的处理：共和国创立者是 `brutus-founder`，刺杀恺撒的是 `brutus`；老加图是已有的 `cato`，小加图是 `cato-younger`；十人委员阿庇乌斯是 `appius-decemvir`，修大道的是 `appius-caecus`；老塔克文 `tarquin-priscus`，“高傲者”塔克文 `tarquin-superbus`；攻入罗马的布伦努斯是 `brennus`（`brennus-delphi` 是入侵希腊的那位）；安东尼是 `mark-antony`（`anthony` 是修士安东尼）；本都王是 `mithridates-6`（`mithridates-1` 是安息王）；克娄巴特拉是 `cleopatra-7`；屋大维用 `augustus`，正式名称“奥古斯都”，“屋大维”和和合本的“该撒亚古士督”写进别名；格拉古兄弟的母亲是 `cornelia`；弗拉米尼乌斯（`flaminius`，死于特拉西梅诺湖）与弗拉米尼努斯（`flamininus`，宣告希腊自由）是两个人。事件与同名地点、人物区分：`mylae-battle`、`trasimene-battle`、`metaurus-battle`、`pharsalus-battle`、`philippi-battle`、`actium-battle`、`alesia-siege`、`sulla-march-on-rome`。
  - 经项目方同意对已有条目作的调整（2026-11-28）：第一次布匿战争补参与者雷古卢斯、杜伊利乌斯；第二次布匿战争补弗拉米尼乌斯、哈斯德鲁巴、马西尼萨；扎马会战、迦太基被毁补马西尼萨；皮洛士战争补登塔图斯、法布里基乌斯、阿庇乌斯·克劳狄乌斯·凯库斯；马其顿战争补弗拉米尼努斯、埃米利乌斯·保卢斯（都只加参与者，文字未动）。庞培的重要度由 3 提到 4，与克拉苏、苏拉、马略持平。统一“恺撒”与古典作家的译名、顶栏是否放出各时期视图，留到第 ④ 批。
  - 地点：卡莱与圣经里的哈兰是同一处，用已有的 `haran`；同盟者战争起事的阿斯库卢姆在皮凯努姆，不是皮洛士战争里已有的 `asculum`（在阿普利亚），没有混用。
  - 译名：恺撒用“恺撒”，“凯撒”“该撒”写进别名；早先为圣经历史录的庞培、大希律等条目正文里写作“凯撒”“斯巴达克”，留到第 ④ 批统一译名时一并处理。
- **第 ④ 批（罗马帝国）的派别、归属、重名与译名**（2026-11-28）：
  - **罗马人内部仍不分色**，皇帝、将领、作家都不设派别。**蛮族出身而终身为罗马效力的统帅也不设派别**：斯提利科（父亲是汪达尔人）、里西梅尔（苏维汇与西哥特王族之后）生在帝国或自幼在罗马军中，一生的官职、对手和结局都在罗马朝廷里，照第 ③ 批“按地域，不按血统”的规矩算罗马人，正文里写明出身。
  - **外族各设一色，新增 7 个**：`germans` 日耳曼诸族（切鲁西人阿米尼乌斯、在意大利称王的奥多亚克；小部族并为一色，同“希腊诸邦”“意大利诸族”的做法）、`goths` 哥特人（弗里蒂格恩、阿陶尔夫，已有的阿拉里克补上；日后的东哥特、西哥特诸王也用这一色）、`vandals` 汪达尔人（盖萨里克；王国延续到 534 年，第 ⑤ 批还有人）、`huns` 匈人（已有的阿提拉补上）、`britons` 不列颠人（布狄卡）、`dacia` 达契亚人（德凯巴鲁斯）；“两河与波斯”泳道新增 `sasanian` 萨珊波斯（阿尔达希尔一世、沙普尔一世、沙普尔二世），与已有的 `parthia`（安息）并列。法兰克人、勃艮第人、伦巴第人、盎格鲁-撒克逊人留到第 ⑤ 批再设色，届时克洛维从无派别改归法兰克人。

## 5. 多语言

- 界面文字：`locales/<语言>/ui.yaml`。
- 内容文字：`locales/<语言>/<实体类型>/<id>.yaml`，缺失时回退到中文并标注"未翻译"。
- 网址带语言前缀：`/zh/person/han-xin`、`/en/person/han-xin`。
- 每个实体挂 Wikidata 编号，新增语言时可批量拉取人名、地名的既有译名，只需人工翻译简介。
- 年代显示也走本地化：中文"公元前 221 年"，英文"221 BC"。

## 6. 技术方案（建议）

| 环节 | 选择 | 理由 |
|---|---|---|
| 站点 | **Astro** 静态站点 + 交互组件 | 内容即文件、无需后端；自带多语言路由与内容校验；详情页利于搜索引擎收录 |
| 时间长河 | **D3**（比例尺、缩放）+ Canvas 绘制 | 数千个对象仍然流畅，语义缩放完全可控 |
| 关系图 | D3 力导向或 Cytoscape.js | 成熟，支持按类型着色与布局 |
| 搜索 | Pagefind | 纯静态，支持中文分词 |
| 数据 | Git 仓库内的 YAML | 可审阅、可追溯、便于协作与翻译 |
| 部署 | 纯静态文件，放到已备案域名的主机上 | 构建产物不需要任何后端，能放静态文件的主机都行；线路与备案由项目方处理 |

字体与脚本全部本地托管，不依赖境外 CDN。

**不用数据库**（2026-11-20 讨论）。做完各主要文明，估计是一两万个人物、几万件事、十来万条关系，全是文字，量不大；访客只读不写。数据量上去以后要做的是：按文明、时期、重要度把数据切成小块，放大到哪里再加载哪里；搜索索引在发布时预先生成；发布前跑校验脚本。只有出现以下需求时才考虑加数据库：访客在线提交纠错或评论；多位编辑在网页后台录入；整库导入 CBDB 这类几十万条的外部数据。
