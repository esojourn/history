同一段历史，三种摆法

三个方案用的是同一份示例数据：秦至西汉前期，28 个人物、14 件大事、46 条关系。每个框里都是能操作的真页面，上面是桌面版，下面是手机版。

A 时间长河B 历史长卷C 人物关系网我的建议

方案 A时间长河

单独打开

横轴是时间，每个文明一条泳道。像地图一样缩放：远看是各文明的时代，放大到朝代后，人物的生卒条和事件自己浮出来。选中一个人，他和别人的关系线才亮起。

在框里试试

  • 点左上角的“世界”，再用滚轮一路放大到秦汉。
  • 鼠标在图上移动，左栏会显示这一年每个文明处在哪个时期。
  • 点“汉高祖”，看十五条关系线各自落在哪一年。
  • 手机版点“朝代”，切换不同文明。

长处

  • 谁先谁后、谁和谁同时在世，不用读数字就能看出来。
  • 多个文明天然并排，同一年各地在发生什么一目了然。
  • 从六千年到一个人的一生，是同一张图，不用换页面。

短处

  • 第一次用需要学会缩放。
  • 手机上要改成竖排，一次只能看一个文明。
  • 三个方案里制作工作量最大。

方案 B历史长卷

单独打开

像读一本书，从上往下滚。每个朝代一章：先是大事，再是人物，一人一行。人名都是链接，点一下就滚到那个人。旁边一栏写着同一时期世界其他地方的情况。

在框里试试

  • 往下滚，看左栏目录和右栏“此时的世界”怎么跟着变。
  • 在“鸿门宴”下面点“范增”，页面会滚到他那一行。
  • 比较每个人名字右边的横条：它们用的是同一把尺。

长处

  • 不用学，会滚动就会用；手机上体验最好。
  • 文字完整，适合从头读到尾，也最容易被搜索引擎收录。
  • 制作最简单。

短处

  • 关系只是一串人名，看不出整体的网。
  • 内容一多页面就很长，跨朝代、跨文明对照要靠来回滚动。
  • “直观”程度最弱，更像一本排得好看的年表。

方案 C人物关系网

单独打开

人物是圆点，关系是连线，整张网一眼看全。横向大致按年代，纵向按阵营。拖动底部的年份，只留下那一年在世的人。手机上一次只看一个人，相关的人围成一圈。

在框里试试

  • 点任意一个人，只留下他的关系；点空白处恢复。
  • 拖动底部滑块，从前 221 年拖到前 154 年，看人物一批批换场。
  • 手机版点周围的人，把他换到中间。

长处

  • 人物关系最直观，谁是枢纽、哪几个人自成一团，一看就知道。
  • 顺着关系一个个点下去，探索起来最有趣。

短处

  • 年代只是大致位置，寿命长短、在位多久都看不出来。
  • 没有朝代主线，也放不下多个文明。
  • 人一多就成一团线，每个朝代都得单独一张图。

我的建议：A 做主干，B 和 C 各取一部分

你最初提的四点里，“朝代主线”“年代先后写清”“各文明并列”都是时间上的事，只有 A 能同时做到。所以主视图用 A。

C 不单独成页，而是放进人物详情：点开一个人，除了文字，还能看到以他为中心的那一圈关系（就是 C 的手机版那个样子）。B 的写法用在详情页和手机端的朝代页，保证每个朝代、每个人都有一页能从头读到尾的文字。

A 时间长河B 历史长卷C 人物关系网
年代先后、寿命长短直接看出来靠读数字，横条辅助只有大致位置
人物关系选中后显示连线只是人名列表整张网都在
多个文明对照并排泳道旁栏文字做不了
手机上可用，要改竖排最顺手可用，一次一个人
内容很多时靠缩放分层，撑得住页面变得很长容易乱成一团
上手难度要学缩放不用学点一下就会
制作工作量最大最小中等

示例数据只为演示形式：年代取通行说法，还没有逐条核对出处；并立政权、世界各文明的分期都做了简化。生年不详的人物画成一头渐隐的条。带虚线边框的时期是传统说法，斜线底纹的时期只排先后、不标年份。
