核实过、但定稿没有用的句子（都对得上原文，留作参考）：

- 萧何的原话：“诸将易得耳。至如信者，国士无双。”（一般的将领好找，像韩信这样的，全国没有第二个。）
- 被抓时韩信说：果然像人们说的，“狡兔死，良狗亨”，“天下已定，我固当亨！”（兔子打完了，猎狗就该下锅；天下太平了，我本来就该被煮。）
- 临刑时韩信说：“吾悔不用蒯通之计，乃为儿女子所诈，岂非天哉！”（蒯通是劝他自立为王、三分天下的谋士。）
- “且喜且怜之”为什么喜、为什么怜，史书没写。要解释的话只能说“后人的理解是”。

**关于“韩信是否真谋反”**：《淮阴侯列传》写得很具体：陈豨赴任前，韩信拉着他的手说“吾为公从中起，天下可图也”；陈豨反后，韩信“阴使人至豨所”，又“谋与家臣夜诈诏赦诸官徒奴，欲发以袭吕后、太子”；篇末“太史公曰”也说他“乃谋畔逆，夷灭宗族，不亦宜乎”。查到的洪迈也没有怀疑，他在下一条“彭越无罪”里说韩信、英布、彭越三人“越独为冤”。后世有人怀疑韩信是被罗织罪名，这一点是凭记忆，这次**没有查到可以核对的原文**。所以这一版照 README 的口径只说“有人告发”，不说“有争议”。
