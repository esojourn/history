## 一、《韩信：追他回来的人，送他去死》

- 状态：**初稿**（2026-11-24）
- 依据：网站条目 `person/han-xin`、`event/hanxin-death`，二者有查过的来源（《史记·淮阴侯列传》《史记·高祖本纪》《汉书·高帝纪》）。
- 待定：是否加一句点明“韩信是否真谋反，后世有争议”。

| 画面 | 旁白 |
|---|---|
| 游戏素材 | 王者峡谷里，韩信是来去如风的刺客。 |
| 网站：点开韩信 | 真实的韩信不是刺客，是统帅，汉军的大将军。 |
| 放大到前 206 年 | 他先跟项羽，献策没人听；转投刘邦，还是不受重用，干脆跑了。 |
| 聚焦萧何 | 丞相萧何亲自把他追回来，对刘邦说：这个人，国士无双。 |
| 划过战役节点 | 拜将之后，定三秦，俘魏王，背水破赵，袭取齐国，最后会兵垓下，项羽败亡。 |
| 人物卡 | 天下一定，兵权被夺。齐王改成楚王，楚王又降成淮阴侯。 |
| 事件“韩信被杀” | 公元前 196 年，刘邦出征在外，有人告发韩信谋反。吕后怕他不肯来，找萧何商量。 |
| 同上 | 萧何亲自登门：“虽疾，强入贺。”身体不好，也勉强去一趟吧。 |
| 同上 | 韩信一进长乐宫，就被武士绑了，斩于钟室，夷灭三族。 |
| 聚焦刘邦 | 刘邦回来听说，《史记》只写了几个字：且喜且怜之。 |
| 四人连线同屏 | 后人说：成也萧何，败也萧何。 |
| 结尾卡 | 韩信、刘邦、吕后、萧何是怎么连在一起的？历史长河，扫码来看。 |

可以配地图的地名：井陉（背水破赵）、垓下、长安长乐宫。

## 二、《兰陵王：一句“家事”，一杯毒酒》

- 状态：**初稿**（2026-11-24）
- 依据：网站条目 `person/gao-changgong`、`event/mangshan-zhizhan`。**这两条是凭记忆写的，未经查证**；发布前要对照《北齐书·文襄六王传》核实，尤其是引文“家事亲切，不觉遂然”，以及面具一说的出处（《旧唐书·音乐志》）。

| 画面 | 旁白 |
|---|---|
| 游戏素材 | 峡谷里的兰陵王，戴着面具，隐身潜行。 |
| 网站：点开兰陵王 | 历史上他叫高长恭，北齐的宗室。面具这件事，还真有来历。 |
| 人物卡 | 史书说他相貌柔美、性情勇猛。唐代人的记载说，他上阵常戴面具，用来威慑敌人。 |
| 事件“邙山之战” | 公元 564 年，北周大军围困洛阳。他带五百骑兵杀进敌阵，一路冲到金墉城下。 |
| 同上 | 城上守军认不出他。他摘下头盔，露出脸，城上才派兵接应。周军溃退。 |
| 同上 | 将士们为他作歌，就是《兰陵王入阵曲》。 |
| 聚焦后主高纬 | 后来皇帝，也就是他的堂弟，问他：冲得那么深，万一失手怎么办？ |
| 同上 | 他答：“家事亲切，不觉遂然。”自家的事，上了心，不知不觉就冲进去了。 |
| 同上 | 皇帝忌讳的，正是“家事”这两个字。 |
| 人物卡 | 他察觉了，故意收受财物败坏名声，又称病不出。没有用。 |
| 时间轴到 573 年 | 573 年，毒酒送到。他喝了。死前，把别人欠他的债券全部烧掉。 |
| 事件“北周灭北齐” | 四年后，北齐亡国。 |
| 结尾卡 | 历史长河，扫码来看。 |

可以配地图的地名：洛阳金墉城与邙山、邺城。
