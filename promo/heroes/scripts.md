## 二、《兰陵王：一句“家事”，一杯毒酒》

- 状态：**定稿**（2026-11-24，项目方确认；已对照原始史料核实）
- 依据：网站条目 `person/gao-changgong`、`event/mangshan-zhizhan`（这两条是凭记忆写的）。文案用到的史实已逐条对照原文，见下面“核实记录”。
- 定稿时定下的：标题保留“毒酒”（原文是“毒药”，他自己说“而遭鸩也”），旁白说“毒药”；年份说“564 年冬”；结尾加一句引向网站连线的话；地图只在“围困洛阳”一句配洛阳、金墉城、邙山的局部图，邺城不配；片尾史料用小字显示、不念。
- 时长：项目方 2026-11-24 同意这一集放宽到约一分半钟（旁白约 450 字），不删。
- 2026-11-24 项目方意见：“家事”为什么犯忌、他察觉了什么、自污的用意，都要给不熟悉历史的观众解释一句；片尾写明核实过哪些原始史料。已照改。

| 画面 | 旁白 |
|---|---|
| 游戏素材 | 峡谷里的兰陵王，戴着面具，隐身潜行。 |
| 网站：点开兰陵王 | 历史上他叫高长恭，北齐的宗室。面具这件事，还真有来历。 |
| 人物卡 | 史书说他“貌柔心壮”。唐代的《教坊记》说，他嫌自己的相貌镇不住敌人，就刻了木头面具，上阵时戴上。 |
| 事件“邙山之战” | 公元 564 年冬，北周大军围困洛阳。他带五百骑兵杀进敌阵，一路冲到金墉城下。 |
| 同上 | 城上守军认不出他。他摘下头盔，露出脸，城上才派弩手下来接应。齐军大胜。 |
| 同上 | 将士们为他作歌，就是《兰陵王入阵曲》。 |
| 聚焦后主高纬 | 后来的皇帝，也就是他的堂弟，对他说：冲得太深，万一失利，后悔都来不及。 |
| 同上 | 他答：“家事亲切，不觉遂然。”自家的事，上了心，不知不觉就冲进去了。 |
| 同上 | 皇帝听了，却起了疑。史书只记了一句：“帝嫌其称家事，遂忌之。” |
| 同上 | 后人的理解是：国家是皇帝的。一个手握兵权、刚立了大功的堂兄，把国事说成“自家的事”，听起来就像这江山也有他一份。 |
| 人物卡 | 他察觉到皇帝在防他，怕的是自己威名太盛。于是故意收受财物，把名声弄脏：名声坏了，威望低了，皇帝也许就放心了。 |
| 同上 | 部下点破他：朝廷真要猜忌你，这反倒成了治罪的把柄。劝他称病回家。他想退，却没能退成。 |
| 时间轴到 573 年 | 573 年，皇帝派人送来毒药。他喝了。临死那天，把别人欠他的债券全部烧掉。 |
| 事件“北周灭北齐” | 四年后，北齐亡国。 |
| 结尾卡 | 他和后主高纬、斛律光、宇文护是怎么连在一起的？历史长河，扫码来看。 |
| 结尾卡上的小字（只显示，不念） | 史实核对自：《北齐书》兰陵武王长恭传、武成纪、后主纪，《教坊记》（维基文库电子版）。 |

配地图：只在“围困洛阳”一句配洛阳、金墉城、邙山的局部图。

网站条目里和原文有出入的地方（已告知项目方，条目未改）：

1. `person/gao-changgong`“又称病不出”——原文是没能退成。
2. `person/gao-changgong`、`event/mangshan-zhizhan`“城上才放下弓弩”——原文“下弩手救之”是派弩手下去救他。
3. `person/gao-changgong`“北周与突厥联军围攻洛阳的金墉城”——《武成纪》里围洛阳的是周将尉迟迥，突厥同时在打幽州，不是联军围城。
