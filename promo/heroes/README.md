# 《峡谷之外》系列短片 · 制作标准

用王者荣耀里的人物，讲他们在真实历史中的故事，带出“历史长河”网站。这一页记录项目方已经定下的事项，后面每一集都按这里做。**原则有调整时，先改这一页，再动手做。**

- 文案（初稿与定稿）：[scripts.md](scripts.md)
- 素材清单与出处：见本页“素材”一节；素材文件本身放在 `promo/out/heroes/`，不进仓库
- 录屏、配音、合成的通用做法：[../README.md](../README.md)
- 已出的成片和重出的办法：见本页“六、成片”

## 二、制作流程

1. **选题**：从候选表里选人物，优先选网站上已有人物和事件条目的。
2. **文案**：写进 [scripts.md](scripts.md)，标“初稿”。项目方商定后改标“定稿”。**没有定稿的不做视频。**
3. **素材**：按定稿收集游戏图片或视频、局部地图，出处记入本页。
4. **录屏**：按定稿录网站界面（手机画幅）。
5. **配音与合成**：沿用 `promo/` 现有的配音、合成脚本。
6. **导出讲稿与核实记录**：成片做好后运行 `node promo/heroes/export-txt.mjs`（只导某一期：`node promo/heroes/export-txt.mjs lanling2`），在成片旁边生成 `promo/out/heroes/<编号>-<期>/<期>.txt`（例：`002-lanling/lanling.txt`）。内容从 [scripts.md](scripts.md) 里那一篇原样取出，格式是项目方 2026-11-26 改定的，每块之间空一行：
   ```
   《峡谷之外的真实历史》二：兰陵王 - 一句“家事”，一杯毒酒
   https://lishi.alz-ai.cn/zh/#person/gao-changgong
   峡谷里的兰陵王，戴着面具，隐身潜行。
   ……（旁白一段一行，不编号、不写画面）
   史实核对自：《北齐书》兰陵武王长恭传、武成纪、后主纪，《教坊记》（维基文库电子版）。
   查过的原文：
   · 《北齐书》卷十一《文襄六王传·兰陵武王长恭》 https://zh.wikisource.org/wiki/北齊書/卷11
   · ……
   ```
   - 标题：系列名《峡谷之外的真实历史》+ scripts.md 里的篇序 + 篇名，篇名里的“：”换成“ - ”。
   - 网址：网站上这个人物的页面，和结尾二维码指向的一致。
   - 旁白：只放要念的；第一屏标题画面等“只显示、不念”的字不放。
   - 史实核对自：结尾卡上那行小字。
   - 查过的原文：scripts.md 核实记录里的书目清单（带链接）。逐条对照表、画面说明、制作说明都不放，仍留在 scripts.md 里。所以**每篇的核实记录都要有“查过的原文：”清单**，没有的话脚本会报错。
   
   文案或核实记录改了要重新导出；txt 只是导出件，要改就改 scripts.md。新增一期时在脚本开头的 `EPISODES` 里加一行（期名、scripts.md 第几篇、网站人物编号）。
7. **发布前检查**：对照本页第四节逐项过一遍。

## 三、每集的规格（AI 的建议，项目方未否定，可调整）

- 系列名暂定《峡谷之外》。
- 时长 45–60 秒，旁白 200–250 字。需要给观众补背景解释的，可以放宽：兰陵王一集经项目方同意放宽到约一分半钟（2026-11-24）；实际成片 1 分 52 秒（含 1 秒片头封面），原因见“六、成片”。韩信第一篇同样放宽，旁白约 530 字（2026-11-25）；实际成片 1 分 55 秒（含 1 秒片头封面），见“六、成片”。
- 结构：
  0. 第一屏：标题画面（成片第一帧，也是平台上的预览图），停 1–2 秒后接正片。从上到下：
     - 系列标题“峡谷之外的真实历史”，中号楷体、浅米色（竖版居中靠上，横版放左上）；
     - 这一集的大标题，楷体粗字，全屏最大；太长就分两行，后一行用金色突出；
     - 人物名，小字、灰白色，放在大标题下面；
     - 右下角小字“图片来自《王者荣耀》官方”。
     - 背景是官方游戏图片：竖版用竖图居中、横图模糊垫底；横版用横图铺满，人物偏右，左边压暗放字。字不要压住人物的脸。
     - 样张（项目方 2026-11-26 认可）：`promo/out/heroes/title-sample/title-v.png`（竖版）、`title-h.png`（横版），生成脚本同目录 `make.mjs`，都不进仓库（含游戏图片）。
  1. 开头约 3 秒：游戏人物素材，加一句反差的话。
  2. 网站画面：时间轴放大到那个年代，点开人物，相关的人聚到同一屏。
  3. 故事：沿着网站上的事件节点讲；提到地名时插入局部地图。
     - **史书原文文字卡**（项目方 2026-11-26 认可，以后常用）：旁白讲到史书的记载时，在画面上盖一张“《某书》原文”的卡，打出那一句原文，旁白说到的几个字用红色突出；网站的卡片照常露出一部分（竖版盖住手机画面上半截的关系图，横版盖住左边的时间轴，右边人物卡照常）。网站条目里没写到的事，靠它给画面；网站上写了的，也可以用它把原话亮出来。
     - 卡上的原文必须和这一篇核实记录“原文”一栏**逐字一致**，脚本开录前自动对照，对不上就停。只放原文，不放白话翻译（翻译在字幕里）；“后人的理解”那类解释不配原文卡。
     - 一张卡跟一句旁白，念到才出现，接下一张时交叉淡入淡出（两张卡高矮不一，不交叉的话旧卡的下沿会露出来）。做法和代码见兰陵王第二篇的 [lanling2.mjs](lanling2.mjs)、[lanling2-h.mjs](lanling2-h.mjs)。
  4. 结尾卡：二维码和网址；下方用小字列出核实过的原始史料（只显示、不念，是 AI 的建议）。只列确实打开核对过的。
- 游戏素材只作引子，每集合计不超过几秒到十来秒，主体是网站画面。

## 四、内容口径

沿用网站的内容原则（见仓库根目录 `CLAUDE.md` 和 `docs/content-guide.md`），短片里尤其注意：

1. **只讲史书有记载的。** 不编对话、数字、细节。引用原话时用史书原文，再用白话解释；画面上用文字卡打出原文（见第三节）。
2. **有争议的不下结论。** 例：韩信是否真的谋反，文案只说“有人告发”。
3. **说清楚是谁记的。** 后世的说法和当时的正史分开，例：兰陵王戴面具出自唐代人的记载，不是《北齐书》本传。
4. **文案依据的网站条目如果是凭记忆写的**（`sources` 为空），发布前要对照原始史料核实文案里用到的每一处，尤其是引文。
5. 游戏里的设定只在开头提一句作对比，不评价游戏。
6. **解释要分清哪句是史书的、哪句是后人的理解。** 史书没写原因的地方（例：皇帝为什么忌讳“家事”），可以用后人通行的理解来解释，但旁白里要说明“后人的理解是”。
7. **每篇文案后面附核实记录**：逐条写明对照了哪本书、哪一篇、原文怎么说、对不对得上；片尾列出的史料以这份记录为准。
8. **番外篇的例外**（项目方 2026-11-26 定）：标题标明“番外”的篇目，可以讲传说和后世的说法，没有非常严谨的史料也可以。但旁白和画面上都要说清楚哪些是史书记载、哪些是传说（旁白用“传说”“相传”“据日本的记载”这类话标明），并写明传说出自哪里、大约什么时候开始流传；核实记录的“结论”一栏写明“传说”及出处。正篇的口径不变，仍按第 1–7 条。

### 兰陵王一集是怎么做的

- 旁白在 [lanling.yaml](lanling.yaml)，与 [scripts.md](scripts.md) 的定稿逐字一致（脚本开录前会自动对照，对不上就停）。第 4 行拆成两段配音，只是为了知道地图该放多久，字没有动。
- 片头封面：第一帧就是官方游戏图片做的封面（不再从黑屏淡入），社交平台的预览图就是它；停 1 秒后淡入正片，旁白和后面的画面整体往后挪 0.6 秒，别的都没变（项目方 2026-11-25 要求）。
- 画面与文案“画面”一栏的对应：开头官方图片 → 在网站上搜索“兰陵王”并点开 → 人物卡 → 地图（只在“公元 564 年冬，北周大军围困洛阳”一句）→ 事件“邙山之战” → 从关系图点“北齐后主”，看他的卡片和关系图 → 回到兰陵王的人物卡 → 在他的关系图上放大到 573 年“赐毒酒”那条线 → 事件“北周灭北齐” → 结尾卡。
- 结尾卡：二维码、网址，最下面小字是核实过的史料（只显示、不念）。二维码打开的是兰陵王的关系图（`…/zh/#person/gao-changgong`），卡上显示的网址仍是首页。
- 字幕按标点自动断成短句，时间对齐到配音里的停顿。
- **时长比约定的一分半长**：定稿旁白连标点 514 字，按功能介绍片的语速（1.1 倍）念完要两分钟出头；调到 1.25 倍、段间停顿压到四分之一秒后正片是 1 分 51 秒，加片头封面后 1 分 52 秒。再快听起来就赶了，尤其是几句文言引文；要压到一分半，只能再加快语速或删字，这要项目方定。
- **还没做到、要项目方知道的**：
  1. 配音是机器合成的，AI 听不到成品，“高长恭”“邙山”“金墉城”“斛律光”“宇文护”“貌柔心壮”这些字读得对不对，要请项目方听一遍。
  2. 网站关系图上那条线的标注是“赐毒酒”，旁白说的是“毒药”（原文是“毒药”，他自己说“而遭鸩也”）。这是网站条目的事，这次没有动。
  3. 北齐后主（`person/gao-wei`）、北周灭北齐（`event/beizhou-mie-beiqi`）两条是凭记忆写的，片中出现了它们的卡片文字；旁白用到的史实已另行核实，卡片上的其他文字没有核实。
  4. 官方游戏视频没有拿到，开头用的是图片。

### 兰陵王·横版是怎么做的

- 脚本 [lanling-h.mjs](lanling-h.mjs)。内容和竖版完全一样：旁白同一份 [lanling.yaml](lanling.yaml)（开录前对照定稿），配音直接用竖版做好的（`promo/out/heroes/002-lanling/voice/`，没有重配），音乐、字幕断句、片头封面的做法都同竖版。中间文件放在 `promo/out/heroes/002-lanling/h/`，竖版的 `lanling.mp4` 和它的中间文件没有动。
- 网站画面是桌面版（1920×1080、字号 1.3 档，同功能介绍片），用假鼠标操作：点搜索框输入“兰陵王”→ 时间轴飞到南北朝，右边出他的人物卡，鼠标指着“相貌柔美而性情勇猛”“唐代的《教坊记》”→ 地图（只在“公元 564 年冬，北周大军围困洛阳”一句，盖住左边的时间轴，右边人物卡照常露出），同时在卡片里点“邙山之战”→ 事件卡滚到五百骑兵、摘头盔、《兰陵王入阵曲》→ 点“返回 兰陵王”，在时间轴上点“北齐后主”，卡片滚到“先后杀害斛律光、兰陵王……”→ 鼠标移到后主和兰陵王之间“赐毒酒”那条连线上，滚轮放大 → 点回兰陵王，卡片滚到“家事”和自污那一段 → 鼠标移到他生卒条的末端，顶上显示“公元 573 年”，再放大 → 在时间轴上点事件“北周灭北齐”→ 结尾卡。
- 和手机版的不同：桌面版没有单独的“关系图”页面，关系是时间轴上的连线，人物卡固定在右边，所以“看关系图”“放大到那条线”都在时间轴上用滚轮做；卡片一屏放得下的内容多，就用鼠标指着旁白说到的那一句。
- 地图用的是竖版那张 `lanling-luoyang`（近正方形），没有另画横幅的；“示意图”字样在图上。
- 字幕在画面下方正中，白字半透明深色底，宽度不会盖到右边的人物卡。
- 结尾卡：左边是兰陵王关系图的电脑画面，右边二维码、网址；下面小字是核实过的史料（只显示、不念）。二维码打开 `…/zh/#person/gao-changgong`，已用程序从成片的画面里扫出确认。
- 时长 1 分 53 秒（片头封面 1 秒 + 正片 1 分 52 秒），比竖版长 1 秒左右：桌面版鼠标移动、点开卡片的动作比手机版略慢，个别段落后面多停了一点。
- **还没做到、要项目方知道的**：竖版列的四条（配音读音、“赐毒酒”与“毒药”、两条凭记忆写的条目、没有游戏视频）横版同样存在；另外桌面版人物卡上能看到的文字比手机版多，“北齐后主”“北周灭北齐”两张卡上没核实的文字在片中更清楚可读。

“龙且”要是听下来还是读错，或者别的字读错，在 `hanxin-kuaxia.yaml` 顶层的 `pron` 里加一条“原字: 同音字”，重新配音再合成即可；旁白和字幕不受影响。
