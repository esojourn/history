## 二、制作流程

1. **选题**：从候选表里选人物，优先选网站上已有人物和事件条目的。
2. **文案**：写进 [scripts.md](scripts.md)，标“初稿”。项目方商定后改标“定稿”。**没有定稿的不做视频。**
3. **素材**：按定稿收集游戏图片或视频、局部地图，出处记入本页。
4. **录屏**：按定稿录网站界面（手机画幅）。
5. **配音与合成**：沿用 `promo/` 现有的配音、合成脚本。
6. **发布前检查**：对照本页第四节逐项过一遍。

## 三、每集的规格（AI 的建议，项目方未否定，可调整）

- 系列名暂定《峡谷之外》。
- 时长 45–60 秒，旁白 200–250 字。需要给观众补背景解释的，可以放宽：兰陵王一集经项目方同意放宽到约一分半钟（2026-11-24）。
- 结构：
  1. 开头约 3 秒：游戏人物素材，加一句反差的话。
  2. 网站画面：时间轴放大到那个年代，点开人物，相关的人聚到同一屏。
  3. 故事：沿着网站上的事件节点讲；提到地名时插入局部地图。
  4. 结尾卡：二维码和网址；下方用小字列出核实过的原始史料（只显示、不念，是 AI 的建议）。只列确实打开核对过的。
- 游戏素材只作引子，每集合计不超过几秒到十来秒，主体是网站画面。

## 四、内容口径

沿用网站的内容原则（见仓库根目录 `CLAUDE.md` 和 `docs/content-guide.md`），短片里尤其注意：

1. **只讲史书有记载的。** 不编对话、数字、细节。引用原话时用史书原文，再用白话解释。
2. **有争议的不下结论。** 例：韩信是否真的谋反，文案只说“有人告发”。
3. **说清楚是谁记的。** 后世的说法和当时的正史分开，例：兰陵王戴面具出自唐代人的记载，不是《北齐书》本传。
4. **文案依据的网站条目如果是凭记忆写的**（`sources` 为空），发布前要对照原始史料核实文案里用到的每一处，尤其是引文。
5. 游戏里的设定只在开头提一句作对比，不评价游戏。
6. **解释要分清哪句是史书的、哪句是后人的理解。** 史书没写原因的地方（例：皇帝为什么忌讳“家事”），可以用后人通行的理解来解释，但旁白里要说明“后人的理解是”。
7. **每篇文案后面附核实记录**：逐条写明对照了哪本书、哪一篇、原文怎么说、对不对得上；片尾列出的史料以这份记录为准。

收集办法（其他人物照此办理）：

- 人物编号查官网的英雄列表 `https://pvp.qq.com/web201605/js/herolist.json`。
- 图片地址：`https://game.gtimg.cn/images/yxzj/img201606/skin/hero-info/<编号>/<编号>-mobileskin-<序号>.jpg`（竖版），把 `mobileskin` 换成 `bigskin` 是横版。序号 1 是默认造型。
- 竖版图分辨率不高（727×1071），铺满 1080×1920 的画面会发虚；用的时候放在画面中部，或用横版图裁切。

**游戏视频：还没有拿到。** 官网每个英雄有一支官方介绍视频（韩信 <https://pvp.qq.com/v/detail.shtml?G_Biz=18&tid=49146>，兰陵王 `tid=43976`），放在腾讯视频上，不能直接下载。眼下先用图片加缓慢推近的效果。要用视频的话有两条路：项目方自己在游戏里录几秒；或由 AI 在浏览器里播放官方视频并录屏（画质会打折扣）。

### 地图

- 只用局部，不出现完整的国家轮廓和国界。
- 自己画的示意图，脚本是 [map.mjs](map.mjs)：`node promo/heroes/map.mjs` → `promo/out/heroes/maps/`。样张见 [samples/](samples/)。
- 底图数据：Natural Earth 1:1000 万的河流、湖泊、海岸线（公共领域，不需要署名）。从 <https://github.com/nvkelso/natural-earth-vector> 的 `geojson/` 目录下载 `ne_10m_rivers_lake_centerlines`、`ne_10m_lakes`、`ne_10m_coastline` 三个文件，放到 `promo/out/heroes/ne/`。
- **两处不精确，图上已注明“示意图”**：河流是今天的河道（黄河下游古今不同）；地点坐标是凭记忆写的大致方位，古城按今天的所在地估，没有查证。垓下的位置本身有争议。
- 网站数据里这些地点的经纬度目前还是空的；以后网站做地图功能、查证了坐标，这里改用网站的数据。
